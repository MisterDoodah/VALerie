# Changelog

## v0.1.0 - Concept Baseline

Initial public concept for the Enterprise AI Value Engine.

Includes:

- Fictional customer portfolio across enterprise and startup accounts.
- Three-persona framing: customer AI owner, salesperson, and success resource.
- Lightweight AI success scoring model.
- Weekly leadership rollup script.
- README narrative for AI consumption value, adoption quality, and value realization.

## Future Version Ideas

- `v0.2.0`: Persona-specific data model and views.
- `v0.3.0`: Visual dashboard.
- `v0.4.0`: Value narrative and executive summary generator.
- `v1.0.0`: First complete shareable demo with dashboard, rollup, and demo video.
